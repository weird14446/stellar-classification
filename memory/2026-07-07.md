# 2026-07-07 — star_classification.csv 데이터셋 탐색

`experiment/data-exploration` 브랜치에서 `explore_dataset.py`(`uv run explore_dataset.py`로 실행)를 작성해 데이터셋을 조사했다.

## 데이터셋 크기

- 100,000행 × 18열 (특성 17개 + 타깃 `class`), 메모리 약 19 MB
- 클래스 분포(불균형): GALAXY 59,445 / STAR 21,594 / QSO 18,961

## 특성과 타입

| 구분 | 컬럼 | 타입 |
|---|---|---|
| 측광 (magnitude) | `u`, `g`, `r`, `i`, `z` | float64 |
| 분광 | `redshift` | float64 |
| 위치 | `alpha` (적경), `delta` (적위) | float64 |
| 식별자/메타데이터 | `obj_ID`, `spec_obj_ID` | float64 |
| 식별자/메타데이터 | `run_ID`, `rerun_ID`, `cam_col`, `field_ID`, `plate`, `MJD`, `fiber_ID` | int64 |
| 타깃 | `class` | str (GALAXY / STAR / QSO) |

식별자/메타데이터 컬럼은 물리적 의미가 없으므로 모델 입력에서 제외 대상. 분석은 수치형 특성 8개(`u,g,r,i,z,redshift,alpha,delta`)에 대해 수행.

## 결측치

- **NaN은 전 컬럼에 0개** (명목상 결측 없음).
- 단, **index 79543 한 행**의 `u`, `g`, `z`에 SDSS 오류 센티널 값 **-9999**가 존재 → 사실상 결측. 아래 figure와 통계는 이 값을 제외하고 계산했다. 전처리 시 이 행은 제거하거나 대치 필요.

## 수치형 특성 분포 — `figures/numeric_distributions.png`

- `u,g,r,i,z`: 대체로 10~32 범위. `g,r,i,z`는 쌍봉(bimodal) 형태 — 클래스(별/은하) 혼합이 원인일 가능성이 높음. 추후 클래스별 분포 확인 가치 있음.
- `redshift`: 0 부근에 큰 스파이크(별은 redshift ≈ 0) + 우측으로 긴 꼬리(max 7.01, QSO). 심한 우측 왜도 — 스케일링/변환 검토 필요.
- `alpha`: 0~360 전천에 걸쳐 있으나 서베이 커버리지에 따른 공백 구간 존재. `delta`: -18.8~83.0. 위치 특성은 클래스와 물리적 연관이 없어 특성 제외 후보.

## 전처리 방침 (결정)

1. **결측치**: index 79543 행(u/g/z = -9999) **삭제** → 99,999행. 0.001%라 정보 손실 없음, 대치 불필요.
2. **이상치**: **제거하지 않음**. redshift 이상치는 QSO 판별 신호(위 검증), 측광 이상치는 0.3% 이하 소수이며 물리적으로 유효한 천체일 가능성이 높음.
3. **특성 선택**: 식별자/메타데이터 컬럼과 `alpha`/`delta`(클래스와 물리적 무관) 제외 → `u, g, r, i, z, redshift` 6개로 시작.
4. **스케일링**: `redshift`는 `log1p`(최솟값 -0.01이라 안전) 후 표준화, 측광 5개는 꼬리 영향이 적은 `RobustScaler`.

## 전처리 방침 구현 — `preprocess.py`

위 방침 4가지를 `preprocess.py`로 구현했다 (`uv run preprocess.py`로 데모 실행).

- `load_clean()`: 센티널 행 제거 + 특성 6개/타깃 선택 → 99,999행 (GALAXY 59,445 / STAR 21,593 / QSO 18,961).
- `build_preprocessor()`: `ColumnTransformer` — 측광 5개 `RobustScaler`, `redshift`는 `log1p` → `StandardScaler`. **train split에만 fit할 것** (데모는 80/20 stratified split으로 leakage 없이 fit).
- 스케일 후 train 통계: 측광은 대략 [-3.8, 4.8], redshift는 mean 0/std 1, max 4.66 — NN 입력으로 무리 없는 범위.
- 공용 figure 스타일은 `plot_style.py`로 분리 (explore/compare 스크립트가 공유).

## 은닉층 깊이 비교 실험 — `figures/depth_comparison.png`

`experiment_depth.py` (`uv run experiment_depth.py`). "은닉층 몇 개가 적절한가"를 실험으로 확정.

- 설정: `preprocess.py` 파이프라인(특성 6개), train 64,000 / val 16,000 (test 20,000은 최종 평가용으로 미사용), sklearn `MLPClassifier`(ReLU, adam, batch 512, early stopping), MLP는 seed 3개 평균.

| 구성 | val macro-F1 | val acc | 학습 시간 |
|---|---|---|---|
| LogReg (0층) | 0.9531 | 0.9594 | 0.3s |
| MLP 1층 (64) | 0.9660 ± 0.0010 | 0.9705 | 2.9s |
| **MLP 2층 (64, 32)** | **0.9681 ± 0.0016** | 0.9723 | 3.6s |
| MLP 3층 (64, 32, 16) | 0.9675 ± 0.0016 | 0.9718 | 2.9s |

- 비선형성의 효과는 분명함: 0층 → 1층에서 macro-F1 +1.3%p.
- 깊이의 효과는 미미함: 1층 → 2층 +0.2%p (seed 표준편차와 비슷한 크기), 2층 → 3층은 오히려 하락. 예상대로 얕은 구조로 충분한 문제.
- **결정: 은닉층 2개 (64, 32)를 베이스라인 구조로 채택.** 1층과의 차이가 작으므로 단순함을 우선한다면 1층도 방어 가능.
- 2층 모델 per-class (val): GALAXY F1 0.977, STAR 0.988, **QSO 0.940 (recall 0.911)** — 약점은 QSO 재현율. 개선 후보: class weight 도입(sklearn MLP는 미지원이라 PyTorch 전환 시), 색지수 파생 특성 추가.

## PyTorch 전환 + class weight/색지수 ablation — `figures/torch_improvements.png`

`experiment_torch.py` (`uv run experiment_torch.py`). 채택한 2층 (64, 32) 구조를 PyTorch로 재구현하고(Adam 1e-3, batch 512, val macro-F1 기준 early stopping patience 15), class weight(inverse frequency)와 색지수 파생 특성 4개의 효과를 ablation으로 검증. 분할은 깊이 실험과 동일(train 64k / val 16k / test 20k, seed 42), seed 3개 평균.

| 구성 | val macro-F1 | val QSO recall |
|---|---|---|
| baseline (특성 6개) | 0.9702 ± 0.0003 | 0.9266 |
| + class weight | 0.9679 ± 0.0005 | 0.9394 |
| **+ 색지수 (특성 10개)** | **0.9706 ± 0.0001** | 0.9329 |
| + 둘 다 | 0.9682 ± 0.0003 | 0.9395 |

- PyTorch 재구현 baseline(0.9702)이 sklearn(0.9681)보다 이미 높음 — early stopping을 val macro-F1로 직접 하는 차이로 추정.
- **class weight는 트레이드오프**: QSO recall은 +1.3%p 오르지만 정밀도가 떨어져 macro-F1은 오히려 하락. macro-F1 기준으로는 채택하지 않음. QSO recall이 우선인 요구가 생기면 다시 고려.
- **색지수는 소폭이지만 일관된 개선**(+0.0004, seed 편차 0.0001로 안정적) + QSO recall도 +0.6%p → **채택. 최종 구성: 특성 10개 + class weight 없음.**
- **test set 최종 평가 (20,000행, 색지수 구성)**: macro-F1 **0.9700 ± 0.0002**, accuracy 0.9737. per-class F1: GALAXY 0.978 / STAR 0.985 / QSO 0.947 (recall 0.933). val과 test가 거의 같아 과적합 없음.

전처리 변경: `preprocess.py`에 `COLOR_INDICES`, `add_color_indices()`, `build_preprocessor(color_indices=True)` 추가 (색지수도 RobustScaler).

## 과반수 투표 앙상블 — `figures/ensemble_comparison.png`

`experiment_ensemble.py` (`uv run experiment_ensemble.py`). 최종 구성(PyTorch 2층 (64, 32), 특성 10개, class weight 없음) 모델 10개를 **매 실행마다 새로 뽑는 무작위 시드**로 학습하고(시드는 출력에 기록됨), hard majority voting(동점은 낮은 클래스 인덱스)으로 결합해 test set에서 평가.

- 이번 실행 시드: 937193, 899600, 762320, 2030, 638102, 56880, 772183, 287024, 258431, 498810
- 개별 모델 test macro-F1: **0.9699 ± 0.0006** (범위 [0.9688, 0.9707])
- **앙상블 test macro-F1 0.9703, accuracy 0.9741** (val macro-F1 0.9714)
- 앙상블 per-class test F1: GALAXY 0.978 / STAR 0.986 / QSO 0.947 (recall 0.927, precision 0.967)

해석:

- 앙상블은 개별 평균 대비 +0.04%p로 **개선 폭 자체는 작다** (개별 최고 모델 0.9707보다는 낮음). 이 문제는 단일 모델도 이미 안정적이라(시드 편차 ±0.0006) 투표로 정정할 여지가 크지 않음.
- 실질 이득은 **시드 복불복 제거**: 어떤 시드를 뽑느냐에 따라 0.9688까지 내려갈 수 있는 위험이 사라지고, 개별 모델 10개 중 8개보다 높은 성능이 안정적으로 나온다.
- 비용은 학습/추론 10배. 성능이 최우선이면 채택할 만하고, 단순함이 우선이면 단일 모델(0.9700)로 충분.

## 최종 모델 확정: 저장/추론 파이프라인 + 안정성 검증

"98%대 유지·안정화" 결정에 따라 최고 구성(MLP×3 + XGBoost + HistGB soft voting)을 최종 모델로 확정하고 파이프라인을 정리했다.

**파일 구성**:

- `model.py` — MLP (64, 32) 아키텍처 정의 (torch 외 의존성 없음, 학습/추론 공용)
- `train_final.py` — 최종 모델 학습·저장 (`uv run train_final.py [--seeds 0,1,2] [--outdir models]`). 프로세스 격리 구조(OpenMP 충돌 회피)로 학습 후 `models/`에 preprocessor(joblib), MLP state dict ×3, XGBoost(json), HistGB(joblib), metadata.json(클래스·특성·시드·성능) 저장
- `predict.py` — 저장된 앙상블로 추론 (`uv run predict.py input.csv` → `*_predictions.csv`에 pred_class + 클래스별 확률). 센티널 행은 경고 후 제거, `class` 컬럼이 있으면 정확도 리포트. **인자 없이 실행하면 자가 검증**: test split 재구성 → metadata의 저장 성능과 대조

**검증 결과**:

- 자가 검증 통과: 저장 아티팩트 로드 → test accuracy 0.9788 / macro-F1 0.9755 정확히 재현
- **안정성**: MLP 시드 그룹 3개({0,1,2}, {10,11,12}, {20,21,22})로 전체 파이프라인을 3회 학습한 결과 **test accuracy 모두 0.9788로 동일**, macro-F1은 0.9755/0.9754/0.9754 (편차 0.0001). GBDT 2종은 결정적(seed 42 고정)이고 MLP 시드 변동은 soft voting이 흡수 — 98%대 안정화 달성.
