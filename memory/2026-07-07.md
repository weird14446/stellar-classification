# 2026-07-07 — star_classification.csv 데이터셋 탐색

`experiment/data-exploration` 브랜치에서 `explore_dataset.py`(`uv run explore_dataset.py`로 실행)를 작성해 데이터셋을 조사했다.

## 데이터셋 크기

- 100,000행 × 18열 (특성 17개 + 타깃 `class`), 메모리 약 19 MB
- 클래스 분포(불균형): GALAXY 59,445 / STAR 21,594 / QSO 18,961

## 특성과 타입

| 구분 | 컬럼 | 타입 |
|---|---|---|
| 측광 (magnitude) | `u`, `g`, `r`, `i`, `z` | float64 |
| 분광 | `redshift` | float64 |
| 위치 | `alpha` (적경), `delta` (적위) | float64 |
| 식별자/메타데이터 | `obj_ID`, `spec_obj_ID` | float64 |
| 식별자/메타데이터 | `run_ID`, `rerun_ID`, `cam_col`, `field_ID`, `plate`, `MJD`, `fiber_ID` | int64 |
| 타깃 | `class` | str (GALAXY / STAR / QSO) |

식별자/메타데이터 컬럼은 물리적 의미가 없으므로 모델 입력에서 제외 대상. 분석은 수치형 특성 8개(`u,g,r,i,z,redshift,alpha,delta`)에 대해 수행.

## 결측치

- **NaN은 전 컬럼에 0개** (명목상 결측 없음).
- 단, **index 79543 한 행**의 `u`, `g`, `z`에 SDSS 오류 센티널 값 **-9999**가 존재 → 사실상 결측. 아래 figure와 통계는 이 값을 제외하고 계산했다. 전처리 시 이 행은 제거하거나 대치 필요.

## 수치형 특성 분포 — `figures/numeric_distributions.png`

- `u,g,r,i,z`: 대체로 10~32 범위. `g,r,i,z`는 쌍봉(bimodal) 형태 — 클래스(별/은하) 혼합이 원인일 가능성이 높음. 추후 클래스별 분포 확인 가치 있음.
- `redshift`: 0 부근에 큰 스파이크(별은 redshift ≈ 0) + 우측으로 긴 꼬리(max 7.01, QSO). 심한 우측 왜도 — 스케일링/변환 검토 필요.
- `alpha`: 0~360 전천에 걸쳐 있으나 서베이 커버리지에 따른 공백 구간 존재. `delta`: -18.8~83.0. 위치 특성은 클래스와 물리적 연관이 없어 특성 제외 후보.

## 전처리 방침 (결정)

1. **결측치**: index 79543 행(u/g/z = -9999) **삭제** → 99,999행. 0.001%라 정보 손실 없음, 대치 불필요.
2. **이상치**: **제거하지 않음**. redshift 이상치는 QSO 판별 신호(위 검증), 측광 이상치는 0.3% 이하 소수이며 물리적으로 유효한 천체일 가능성이 높음.
3. **특성 선택**: 식별자/메타데이터 컬럼과 `alpha`/`delta`(클래스와 물리적 무관) 제외 → `u, g, r, i, z, redshift` 6개로 시작.
4. **스케일링**: `redshift`는 `log1p`(최솟값 -0.01이라 안전) 후 표준화, 측광 5개는 꼬리 영향이 적은 `RobustScaler`.
