## 3. 진화 신경망(EDL) 아키텍처 및 알고리즘 설계

### 3.1 비미분 목적 함수(Macro-F1)의 직접 최적화
역전파(Backpropagation)는 연속 미분 가능한 대리 손실함수(Cross-Entropy)를 필요로 하지만, 불균형 다중 클래스 분류의 실제 핵심 지표인 **Macro-F1 Score**는 argmax와 이산적 혼동 행렬로 인해 미분 불가능(non-differentiable)하다.
EDL은 도함수(Derivative-Free) 계산 없이 **Macro-F1 점수 자체를 적합도 함수(Fitness Function)**로 삼아 가중치 공간 $\mathbb{R}^D$를 직접 탐색한다.

### 3.2 모델 아키텍처 (`EDL/models.py`)
- `EvolvableMLP`:
  - 입력 차원: 10 (u, g, r, i, z, redshift + 색지수 4개)
  - 은닉층: (32, 16) -> 파라미터 수 총 931개 (가중치 896개 + 편향 35개)
  - 파라미터 직렬화: `get_flat_params()` (1D NumPy float32 벡터 $\theta$)
  - 파라미터 역직렬화: `set_flat_params(vec)` (PyTorch 텐서에 즉시 로드)
  - **초고속 NumPy forward pass (`forward_numpy`)**:
    Autograd 그래프 생성 오버헤드를 완전히 배제하고, Apple Accelerate / BLAS 기반 C-level 행렬곱을 통해 수십 개 개체(Population)의 배치를 마이크로초 단위로 순전파.

### 3.3 최적화 알고리즘 (`EDL/evolution.py`)
두 가지 현대적 신경진화(Neuroevolution) 패러다임 구현:
1. **자연 진화 전략 (Natural Evolution Strategy, NES / OpenAI-ES)**:
   - 파라미터 평균 $\mu$, 탐색 분산 $\sigma$
   - 대칭 섭동(Antithetic Perturbations): $\theta_i^+ = \mu + \sigma \epsilon_i$, $\theta_i^- = \mu - \sigma \epsilon_i$
   - 순위 정규화(Rank-transformation) 피트니스 쉐이핑을 통한 강건한 pseudo-gradient 추정
   - Adam 옵티마이저를 결합한 $\mu$ 갱신
2. **유전 알고리즘 (Genetic Algorithm, GA)**:
   - 실수 유전체(Real-valued Chromosome)
   - $k=3$ 토너먼트 선택(Tournament Selection)
   - BLX-$\alpha$ 실수 블렌드 교차(Blend Crossover)
   - 적응형 가우시안 돌연변이(Gaussian Mutation)
   - 엘리티즘(Elitism): 상위 엘리트 개체 무손실 보존

## 5. 초기 순수 진화 신경망의 한계 원인 규명 및 극복 (96.48% → 97.38%)

### 5.1 원인 분석
1. **고차원 0차 무작위 섭동의 분산 병목 ($\text{Var}[\mathbf{g}_{\text{NES}}] = \mathcal{O}(D/P)$)**:
   - 파라미터 차원 $D \approx 1,000 \sim 2,889$에 비해 세대당 탐색 개체 수 $P=80$은 40개의 무작위 방향만 프로빙하므로, 저적색편이 QSO와 GALAXY가 겹치는 미세한 비선형 결정 경계를 좁히는 국소 착취(Local Exploitation) 해상도가 부족했다.
2. **계단형(Piecewise-Constant) 이산 적합도 지형**:
   - 순수 이산 `Macro-F1`(`argmax` 기반)만 피트니스로 쓰면 가중치 미세 섭동 시 클래스가 뒤집히지 않는 한 $\Delta f = 0$이 되어 수렴 후반부 신호가 소실된다.
3. **네트워크 표현력 차이**:
   - 초기 EDL은 탐색 차원 축소를 위해 `(32, 16)` (931 파라미터)을 사용한 반면, DL 기준선 MLP는 `(64, 32)` (2,883 파라미터)를 사용했다.

### 5.2 단점 극복 아키텍처 (`EDL/evolution.py`, `EDL/models.py`)
1. **다중 섬 라마르크 진화 신경망 (`MemeticEvolution`, `--algo memetic`)**:
   - 8개의 독립적인 진화 섬(Island Lineage)을 운영하며, 라마르크 국소 미세조정(Lamarckian Local Refinement)으로 고차원 가중치 곡률을 빠르게 학습하고, 다윈적 엘리트 크라우딩(Elitist Crowding) 선택·가중치 교차·돌연변이로 비미분 `Macro-F1`을 직접 향상하는 변이만 생존시킨다.
2. **결정 경계 유전자 6개(`class_scale`, `class_bias`)의 무미분 ES 직접 진화**:
   - 출력층 로짓에 $\mathbf{s} \odot \mathbf{z} + \mathbf{b}$ ($\mathbf{s}, \mathbf{b} \in \mathbb{R}^3$) 6개 경계 유전자를 부여하고, L2 정규화된 진화 전략(ES)으로 불균형 클래스(QSO vs GALAXY) 결정 경계를 `Macro-F1` 기준으로 직접 진화시켰다.
3. **순수 ES 개선 (`NaturalEvolutionStrategy`, `--algo es`)**:
   - QR 분해 기반 **직교 대칭 섭동(Orthogonal Antithetic Sampling)** + **연속 Soft-F1 결합 복합 적합도(`composite_macro_f1_fitness`)** + 분리형 가중치 감쇠(Decoupled Weight Decay) 도입.
4. **다중 섬 명예의 전당 앙상블 (`HallOfFameEnsemble`)**:
   - 진화 과정에서 자연스럽게 형성되는 8개 독립 섬의 챔피언 개체들을 결합하고, 앙상블 결정 승수(`edl_hof_multipliers.npy`)를 ES로 진화시켜 추가 학습 비용 없이 분산을 제거했다.

### 5.3 개선 후 Test Set (20,000건) 최종 성적
- **Single Evolved Champion (64, 32)**: Test Accuracy **97.34%**, Test Macro-F1 **0.9695**
- **Multi-Island Hall-of-Fame Ensemble (64, 32)**: Test Accuracy **97.38%** (+0.90%p 상승), Test Macro-F1 **0.9700** (+0.0101 상승)
  - GALAXY F1: **0.9780** (Recall 97.9%)
  - STAR F1: **0.9846** (**Recall 99.7%**, 4,319개 중 오분류 단 12건)
  - QSO F1: **0.9475** (Precision 96.5%, Recall 93.0%)
- 이로써 동일 아키텍처 `(64, 32)` 기준 기존 역전파 DL 단일 모델(`97.37%` / `0.9700`)의 성능을 완전히 따라잡고 상회함을 확인했다.

## 6. 신경망 구조(Topology)와 가중치(Weights)를 동시에 진화시키는 TWEANN 구현 (97.38% → 97.45%)

### 6.1 설계 배경
기존까지는 은닉층 구조 `(64, 32)`를 고정한 상태에서 가중치만 진화시켰으나, 신경망의 위상(Topology: 은닉층 깊이, 층별 뉴런 수, 활성화 함수, 입력 스킵 연결, 시냅스 희소성) 자체도 유전체(`TopologyGenome`)로 인코딩하여 가중치와 함께 진화시키는 **TWEANN(Topology & Weight Evolving Artificial Neural Network)**으로 확장했다.

### 6.2 핵심 구조 진화 메커니즘 (`EDL/models.py`, `EDL/evolution.py`)
1. **구조 유전체 (`TopologyGenome`)**:
   - `hidden_dims`: 가변 은닉층 깊이(2~4층) 및 층별 뉴런 폭(16~192)
   - `activations`: 층별 독립 비선형 활성화 함수 (`relu`, `gelu`, `silu`, `elu`, `tanh`)
   - `input_skips`: 원본 10차원 입력 특성 $\mathbf{x} \in \mathbb{R}^{10}$을 깊은 은닉층에 직접 연결($[\mathbf{h}_{l-1}; \mathbf{x}]$)하는 스킵 연결 유전자
2. **6가지 함수 보존형 Net2Net 구조 변이 연산자**:
   - `mutate_width(layer, ±Δ)`: **Net2Wider** 방식으로 기존 뉴런을 복제하고 다음 층 출력 가중치를 $1/2$씩 분할하여 구조 확장 직후에도 신경망 출력을 보존하거나, $\ell_1$-노름 하위 뉴런을 가지치기(Pruning)
   - `mutate_add_layer()`: **Net2Deeper** 방식으로 항등 행렬($W = I + \mathcal{N}(0, 0.01^2)$)에 가깝게 초기화된 새 은닉층을 삽입하여 깊이 확장
   - `mutate_remove_layer()`: 불필요한 말단 은닉층 제거
   - `mutate_activation(layer)`: 층별 활성화 함수 진화적 교체
   - `mutate_skip_connection(layer)`: 입력 직결 스킵 연결 생성/해제 (새 스킵 가중치는 $\mathcal{N}(0, 0.015^2)$로 초기화해 급격한 함수 붕괴 방지)
   - `mutate_synapse_pruning(4%)`: 가중치 절대값 하위 4% 시냅스를 0으로 소거하여 희소 연결망 형성
3. **종 분화 보호(Speciation Protection) & 상동 서브행렬 교차(`crossover_with`)**:
   - 구조 변이 직후 20 미니배치의 짧은 국소 적응 기간(Speciation Protection)을 부여하여 새로운 구조가 기존 가중치와 조화를 이룬 뒤 검증 `Macro-F1`로 생존 여부를 평가받게 설계.
   - 서로 다른 층수와 뉴런 폭을 가진 섬(Island) 개체 간에도 공통 부분 행렬($\min(r_A, r_B) \times \min(c_A, c_B)$)을 블렌딩하는 상동 교차(Homologous Sub-matrix Crossover) 구현.

### 6.3 45세대 진화 실험 결과 및 발견된 신경망 구조
- 8개의 독립 섬이 서로 다른 초기 씨앗 구조(1,785 ~ 5,561 파라미터)에서 출발하여 45세대 동안 총 **36회의 유의미한 구조 진화(Structural Mutation)**를 거침.
- **최종 단일 챔피언 구조 (Island 4)**:
  - 초기 `10 -> [80:gelu] -> [40:gelu] -> 3` (2층, 4,249 파라미터)에서 출발하여,
  - Gen 1 `widen(L0+16)` $\rightarrow$ Gen 4 `widen(L1+8)` $\rightarrow$ Gen 19 `prune_synapses(4%)` $\rightarrow$ Gen 28 `add_layer` (3층 심화) $\rightarrow$ Gen 34 `widen(L0+8)` $\rightarrow$ Gen 37 `prune_synapses(4%)` $\rightarrow$ Gen 43 `toggle_skip(L2)` (3번째 은닉층에 입력 직결 스킵 연결 장착)을 거쳐
  - 최종 **`10 -> [104:gelu] -> [48:gelu] -> [48+skip:silu] -> 3` (9,169 파라미터, 활성 시냅스 99.8%)** 구조를 스스로 발명함!
- **Held-out Test Set (20,000건) 최종 성적**:
  - **진화된 단일 챔피언 신경망 (`edl_model.pt`)**:
    - **Test Accuracy: `97.43%` | Test Macro-F1: `0.9706`** (고정 구조 `(64, 32)` 역전파 DL 단일 MLP의 `97.37%` / `0.9700`을 단일 신경망으로도 완벽히 추월!)
  - **이종 위상 명예의 전당 앙상블 (`edl_hof_elites.pt`)**:
    - 진화된 상위 이종 신경망 구조들을 적합도 가중 결합하여 **Test Accuracy: `97.45%` | Test Macro-F1: `0.9709`** 달성 (초기 고정 구조 순수 ES 대비 정확도 `+0.97%p`, Macro-F1 `+0.0110` 향상).
